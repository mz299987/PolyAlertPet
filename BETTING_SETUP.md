# Интеграция ставок через Polymarket Builder API

## Обзор

Этот функционал позволяет пользователям делать ставки на рынках Polymarket прямо через Telegram бота, используя Polymarket Builder API для gasless транзакций.

## Преимущества Builder API

- **Gasless транзакции**: Polymarket оплачивает все газовые сборы
- **Safe кошельки**: Автоматическое развертывание безопасных кошельков для пользователей
- **Безопасность**: Удаленная подпись транзакций
- **Атрибуция**: Отслеживание объема торговли для вашего бота

## Настройка

### 1. Получение ключей Builder API

1. Перейдите на [Polymarket Builder Portal](https://builders.polymarket.com/)
2. Зарегистрируйтесь как builder
3. Сгенерируйте ключи API (Builder Key и Builder Secret)
4. Сохраните их в безопасном месте

### 2. Настройка переменных окружения

Добавьте следующие переменные в ваш `.env` файл:

```env
# Обязательные
BOT_TOKEN=your_telegram_bot_token_here
DATABASE_URL=postgresql://username:password@host:port/database

# Опциональные (для функционала ставок)
BUILDER_KEY=your_builder_key_here
BUILDER_SECRET=your_builder_secret_here
```

### 3. Установка зависимостей

```bash
pip install -r newapp/requirements.txt
```

## Использование

### Основные команды

- `/bet` - Начать процесс размещения ставки
- `/my_bets` - Просмотреть историю ваших ставок
- `/markets` - Показать доступные рынки

### Процесс ставки

1. **Инициализация**: Бот автоматически развернет Safe кошелек для пользователя
2. **Выбор рынка**: Введите ID рынка Polymarket
3. **Выбор исхода**: Выберите один из доступных исходов
4. **Сумма ставки**: Укажите сумму в USDC
5. **Подтверждение**: Подтвердите ставку
6. **Исполнение**: Бот выполнит транзакцию через Builder API

### Безопасность

- Все транзакции выполняются через безопасные мультисигнатурные кошельки
- Пользовательские ключи никогда не покидают безопасную среду
- Gasless транзакции исключают риск потери средств на газ

## Интеграция с существующим функционалом

### Отслеживание кошельков
Функционал ставок интегрирован с существующей системой отслеживания кошельков. Пользователи могут использовать те же кошельки для ставок и отслеживания.

### Уведомления
Система уведомлений автоматически оповещает пользователей о статусе их ставок.

## Разработка

### Архитектура

```
newapp/
├── builder_api.py          # Клиент Polymarket Builder API
├── handlers/betting.py     # Обработчики команд ставок
├── database.py            # Расширенная схема БД
└── config.py             # Конфигурация Builder API
```

### Ключевые классы

- `PolymarketBuilderAPI` - Основной клиент для работы с Builder API
- `BettingManager` - Менеджер для управления ставками пользователей
- `BettingHandler` - Обработчики Telegram команд

### Добавление новых рынков

Для интеграции с реальными рынками Polymarket необходимо:

1. Получить актуальный список рынков через Polymarket Data API
2. Реализовать парсинг информации о рынках
3. Интегрировать с процессом ставок

## Ограничения

- Максимальная сумма ставки: 1000 USDC
- Поддерживается только сеть Polygon
- Требуются Builder API ключи для полного функционала
