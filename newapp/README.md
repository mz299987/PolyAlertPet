# Polymarket Tracker Bot

Улучшенная версия Telegram бота для отслеживания портфелей на Polymarket с расширенной функциональностью.

## 🚀 Возможности

### Основные функции
- **Управление кошельками**: Добавление/удаление кошельков, разделение на обычные и киты
- **Уведомления**: Оповещения о крупных сделках (>$1000), изменениях портфеля, новых событиях
- **Аналитика**: Графики распределения портфеля, топ рынков, анализ волатильности
- **Безопасность**: Валидация адресов, ограничение частоты запросов, аудит действий
- **Мультиязычность**: Поддержка русского и английского языков

### Технические особенности
- Асинхронная архитектура на Python с aiogram 3.x
- Интеграция с Polymarket API
- Кэширование данных для быстрого ответа
- Фоновая синхронизация данных каждые 5 минут
- Обработка ошибок сети/API
- Групповые уведомления для администраторов

## 📋 Требования

- Python 3.8+
- PostgreSQL база данных
- Redis (опционально, для кэширования)
- Telegram Bot Token

## 🔧 Установка

1. **Клонирование репозитория**
```bash
git clone <repository-url>
cd newapp
```

2. **Установка зависимостей**
```bash
pip install -r requirements.txt
```

3. **Настройка переменных окружения**
Создайте файл `.env` на основе `.env.example`:
```bash
BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=postgresql://user:password@host:port/database
REDIS_URL=redis://localhost:6379 (опционально)
ADMIN_IDS=123456789,987654321
PORT=8000
```

4. **Настройка базы данных**
Бот автоматически создаст необходимые таблицы при первом запуске.

## 🚀 Запуск

### Локальный запуск
```bash
python main.py
```

### Запуск на Koyeb
Бот готов к деплою на Koyeb. Убедитесь, что переменные окружения настроены правильно.

## 📖 Использование

### Основные команды
- `/start` - Запуск бота
- `/help` - Справка по командам
- `/status` - Статус портфеля
- `/addwallet [адрес]` - Добавить кошелек
- `/search [запрос]` - Поиск событий
- `/reset` - Сброс лимитов безопасности

### Быстрые действия через меню
- **➕ Мой кошелёк** - Добавить обычный кошелек
- **➕ Кит** - Добавить кошелек кита
- **📊 Мои кошельки** - Просмотр списка кошельков
- **📈 Состояние** - Статус портфеля
- **📊 Аналитика** - Анализ портфеля
- **🔍 Поиск** - Поиск по рынкам
- **⚙️ Настройки** - Настройки бота

## 🔒 Безопасность

- **Валидация адресов**: Поддержка 0x-адресов, Polymarket usernames и ENS доменов
- **Лимиты запросов**: Ограничение 30 запросов в минуту на пользователя
- **Аудит действий**: Логирование всех действий пользователей
- **Санитизация ввода**: Очистка пользовательского ввода от опасных символов

## 📊 Аналитика

### Доступные типы анализа
1. **Распределение портфеля** - Текстовые графики распределения активов
2. **Топ рынков** - Самые активные рынки по объему
3. **Анализ волатильности** - Оценка рисков портфеля

### Текстовые графики
Бот использует символьные графики для визуализации данных:
```
Market Name
██████████░░░░░░░░░░ 50.0% (1000.00 USDC)
```

## 🔔 Уведомления

### Типы уведомлений
- **Изменения портфеля** - При значительных изменениях стоимости
- **Сделки китов** - При сделках >$1000 на отслеживаемых кошельках
- **Новые события** - При появлении новых рынков
- **Важные обновления** - Системные уведомления

### Настройка уведомлений
Уведомления настраиваются через меню ⚙️ Настройки → 🔔 Уведомления

Уровень логирования настраивается через переменную окружения `LOG_LEVEL`.
